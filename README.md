# 🌻 LDR Sunflower Arduino Project

A beginner Arduino project based on light detection and servo motor control.

## 🔧 Components Used

- Arduino
- LDR Sensor
- Servo Motor
- Resistor
- Jumper Wires
- Breadboard

## ⚙️ Working

The LDR sensor detects the intensity of light.

Based on the detected light level, the Arduino controls the servo motor.

The servo changes its position according to the light detected by the sensor.

## 🧠 Concepts Used

- Arduino Programming
- LDR Sensor
- Servo Motor
- Analog Input
- Basic Programming Logic

## 🎯 Learning Outcome

This project helped me understand how sensors can be used with Arduino to control an actuator.
